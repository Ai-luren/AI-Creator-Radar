# Recent repository card probe policy

The 45-day independent repository observation cohort is retained unchanged for comparison and audit. It is not a mandate to repeatedly fetch old model cards. Production model-card probes are restricted to repositories created within seven days; the latest three days take precedence, with the existing due-time ordering and request cap within each tier. Source listing discovery, source cooldowns, card history, original sample denominator and local catalog/parent identity reconciliation remain intact. A repository creation timestamp is not a model release date. Older unresolved items remain honestly unresolved; their absence from the request queue is not proof of a resolved incident. No new scheduler or benchmark change.

Acceptance: test older observation preservation, recent-first bounded budget, existing classification and negative controls; compare actual production card requests without claiming new release coverage from fewer requests.

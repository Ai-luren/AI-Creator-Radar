# P1 第一方产品更新

近期上新独立子页“产品更新”，和正式发布/待复核/官方公告分开。首批即梦公开首页实际展示型号、官方更新日志和教程专区。首页可见标签只是产品观察，不能断言全量开放、下架、权益或首发日期；未出现型号不算停用。首次成功只建基线，后续新标签才是新增观察。HTML 仅解析可见文本，不读取脚本、下载权重或执行站点代码；页面不可读、登录壳、零匹配保留上一次成功记录并退避。用户截图及公开页面搜索记录人工确认 SeedAudio 1.5 观察于 2026-11-27，明确区分人工和自动统计；不推断发布日。两个官方飞书入口当前未成功读取正文，暂作为导航，不冒充自动日志或教程抓取。

扩展方向：第一方产品（可灵、即梦/Dreamina、海螺、Vidu、PixVerse 等）按地区与产品独立来源配置，区分型号上架/下架公告、功能更新、配额与价格、教程；仅合法可读公开来源或用户明确授权接口，登录通知不公开采集、不保存凭据。实际更新日志日期必须从正文取得；不能从观察时间推断。

AIPick 定向查询为补充发现：2026-11-27 GitHub 只读探测 HTTP200，近7天即梦产品25、模型2、SeedAudio 0、微信原文0。提供上游专题和个人 JSON 查询入口，不在公开页面复制聚合文章，不将第三方标题作正式产品证明。公开首页自动探测目前仍返回不可读客户端壳，人工观察与自动成功继续分离。测试从三项发布状态更新为四项明确状态，增加实际产品页打开、原文导航、路由恢复和横向溢出验证。

第二阶段：AIPick 定向查询只保存每个关键词最近7天最多30条的聚合计数，不保存文章ID、URL、标题、摘要或正文；每个模型批次最多一次查询，全局至少1小时、同关键词至少6小时、ETag/304保留原始计数观察时间，403/429/503和数字Retry-After尊重退避；零命中不等于完整覆盖。公开展示仅覆盖诊断与上游个人查询入口。即梦 iOS 中国区使用 Apple 官方公开 Lookup 试点，精确 app id/名称及版本时间核验，只存版本和更新说明哈希、不转载说明全文，不把 App 版本发布当模型发布。网页与移动端独立，不共享可用性。生产实测尚需确认。

## LibTV 多渠道补缺

官网更新入口仍为导航；官网公开功能、官方公众号原文线索、X/B站/抖音/小红书账号、GitHub 技术生态分开标记。官方社媒沿用既有账号和原帖快照；未读正文不得计覆盖，未核验原帖留作发现。公众号原始文章可通过既有 AIHOT/AIPick 精选链接发现，当前受限不绕过访问。GitHub 官方生产插件仓库新增单一固定 main 提交 API，每12小时最多一次正常读取、最多30个提交；只识别明确版本发布、验证仓库及完整提交 SHA、合并与子提交按版本去重，不把普通提交、库创建时间或网页可见状态当发布。永久提交链接与原始日期进入同一产品事件库，近期动态、上新、能力矩阵及历史复用；不是网页模型接入证明。

GitHub 插件 API 遇共享 runner 匿名 403 配额时，使用 Actions 内建短期身份（CI contents:read，生产沿用现有采集作业权限），只发送到固定 api.github.com 插件提交接口，禁止任何重定向，不记录、不持久化 token，不为此增加权限或外部凭据。尊重 403/429/503、Retry-After 和 GitHub 配额重置时间，保留旧数据，不循环重试。

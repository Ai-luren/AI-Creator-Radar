# 新增事件发现时延：前瞻性官方 Feed 观察（2026-11-28）

#94 的五条历史精确时间记录来自历史补录，不能衡量当前实时采集。冻结前瞻性基线 2026-11-28T02:00:38Z（#94 生产采集时点）。新采集只为官方 RSS/Atom 原始发布时间确有秒级时钟和明确时区的条目标注精确时刻。日精度、无时区和更新时间不晋级。采集器历史 firstSeenAt 记录批次启动时间；保留其语义不变，另外在并发读取完成后记录首次精确观察时间上界。同源同时间重复观察保留首次上界，时间冲突阻断测量而非覆盖原事实。原始 200/304 缓存继续按解析器版本失效，不增加请求。

系统审计在现有 priorityDiscoveryLatency 中增加 prospectiveFeedDiagnostic：仅统计基线后发布、基线后真实观察、时间来源和顺序可校验、当前30天留存的官方模型 Feed 文章；按型号家族+规范原文去重，排除冲突，计算2小时内数量、比例、时间上界中位数和最大值。空样本为 awaiting-new-observations，比例为 null。旧历史诊断独立保留。正常收录后精确时间才确认可能使上界较慢，宁可保守，不虚报速度。

这不是独立事件级 SLA：只统计成功观察到的 Feed 文章，无法证明未发现事件、厂商全覆盖或发布阶段同一性；也不是页面发布延迟。正式 priorityDiscoveryLatency 仍 not-measured，后续需要独立观察事件分母（含遗漏）。不新建数据文件、定时任务或额外网络采集，不修改 Mac 任务、基准、事实或 8/8 同阶段门禁。测试覆盖日期精度、实际观察上界、跨轮保留、时间冲突、历史补录、2小时边界与空样本。需 CI 和实际生产后验，不能用无新消息的空集宣布通过。

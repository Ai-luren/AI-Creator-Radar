# Renoise Agent 产品研究纲领

## 北极星目标

帮助用户用创作 Agent 更轻松、可控地获得高质量的图像、视频、声音与商业作品（尤其产品广告、产品发布宣传片、品牌短片）。工作台是个人产品设计与工程协作研究工具，不是追求资讯规模的新闻站。以下是研究目标和待验证标准，不代表 Renoise 已经具备这些能力，不代表公司正式路线图。

## 五项工作职责

| 职责 | 研究产出 |
|---|---|
| 产品体验优化 | 减少重复操作、降低创作门槛、提升可控性和生成效果 |
| 工作流封装 | 将优秀创作过程拆成可复用节点、模板、Agent 技能与工具 |
| 新功能研发 | 从新模型、技术、真实用户需求提炼可验证产品构想 |
| 竞品差异化 | 研究友商产品更新、模型接入、能力、传播及公司动态，找到差异化机会 |
| 创作质量提升 | 按创作环节改善图像、视频、声音和最终成片 |

## Agent 与工程师的共同研究清单

- 意图理解：结构化用户简报、品牌/产品真值、目标受众、交付形式、约束及可编辑性。
- 规划与导演：创意、剧本、视觉风格、分镜、镜头依赖、时长、声音规划；支持用户在重要决策处确认或修改。
- 模型路由：按任务、模型能力、输入输出、参考图、可控性和授权选型；不默认最新模型适合所有任务。记录版本和关键参数。
- 工作流封装：可复用的角色、产品、场景资产与多模型工具契约，保存中间产物；可局部重做、恢复、替换模型，避免整片返工。
- 质量评估与迭代：同素材、同约束对比；记录失败类型、可复现输入、人工审美评审、自动检查的能力边界，验证改进再推广。
- 交付：视频、图像、音频、字幕、品牌落版及可修改项目；一键创作不是取消用户控制，而是减少无价值操作。

## 创作能力地图与验收

| 环节 | 重点能力与待验证质量 |
|---|---|
| 创意策划 | 品牌定位、卖点、目标受众、创意差异、叙事逻辑 |
| 视觉资产 | 人物三视图的身份/体型/服装/视角一致性；场景、产品、道具真值；多样风格 |
| 分镜预演 | 构图、景别、站位、白模、运镜、镜头连续性 |
| 图像与视频 | 图像质量、产品不变形、动作和物理合理性、参考遵循、跨镜头一致性 |
| 音频 | 声线与情绪、对白清晰、配乐、音效、口型及音画同步 |
| 后期与交付 | 剪辑节奏、色彩、字幕、品牌信息、交付规格、局部修改能力 |

场景优先：产品广告/TVC、产品发布宣传（含 UI 动效）、品牌短片、社媒营销、短剧漫剧及视觉实验。不同场景设不同质量权重；不把单一榜单分数当最终成片质量。验收记录须包含输入素材、约束、模型/工作流版本、输出及缺陷、人工评价、耗时/返工和下一步。没有实际测试，不宣称最佳效果或已经优化 Agent。

## 模型能力上限与产品化研究

每个有近期价值的模型优先从官方公告、模型卡和接口规格提取具体能力、模式限制与访问条件。区分原生 4K/8K 与后置超分、最长时长与分辨率的组合限制、3D 运镜/白模参考与真正渲染、原生音频与后期合成、图像/视频理解与实际剪辑执行。大语言模型的结构化规划、视频理解、工具调用及自我纠错均可成为 Agent 研究线索，不预设已经实现专业剪辑。

允许记录具备产品竞争意义的推理成本、速度和资源效率，不跟踪会员套餐、积分折扣或促销。以相同素材、输出规格、质量门槛下的实际总成本（含失败、重试和后期）除以可用交付数衡量经济性；未取得测量值不得判断某模型更便宜。现阶段自动研究维度复用已核验官方来源摘要，摘要不完整时明确待查，不将关键词匹配当能力事实，不另开采集器。

## 情报如何变成行动

1. 最近三天优先：新模型、竞品功能、模型接入、下架、工作流、官方演示；其余七天补缺。自然走红与联合宣发都可成为发现信号，但不推断商业合作。
2. 独立看传播原文、原榜及接入证据；聚合平台重叠不相加，未知接入状态不等于未接入。热点可触发既有官方核验。
3. 关联用户痛点、创作环节与可复用能力；候选模型须核对本方现状、API/授权、输入输出和实际效果。公开资料不能代替 Renoise 内部状态。
4. 形成研发讨论材料：证据 → 场景与痛点 → 竞品做法 → Agent/工具/节点方案 → 同素材最小实验 → 结果与决策。事实、假设、实验结果分开。
5. 四维价值：创作质量、效率、可控性、产品竞争力。无法支持产品决策或创作改善的信息不扩张采集。保持现有证据门禁、请求预算、故障隔离及调度；不引入新的一级导航、数据库或推理 API。

## 现有模块分工

竞品总览优先模型接入机会及近期产品动作；功能矩阵用于能力对比；创新机会用于 Agent/工作流原型与最小验证；模型库、榜单、案例及开源工具提供选型和实操证据；传播信源候选辅助发现，不作为合作名单。长期维护及验收依照 AGENTS.md、DESIGN.md 和运行手册。

创新机会优先展示有近期证据的商业创作任务验证（产品广告、连续叙事、Agent 编排、声音交付），复用原有证据数据。每项明确固定输入、当前产品基线、候选 Agent 方案、质量及体验验收。首次可用作品时间、人工操作、返工及有效交付只作为待测指标，用户持续使用必须由授权的实际产品数据验证；不从公开传播量推算留存，不填造结果。

质量任务同时覆盖人物三视图、角色风格资产及视觉文字/品牌校验。官方日志同一入口的不同具名日期条目分别保留；聚合原文跨来源去重；卡片优先展示不同证据类型，关联记录数量不是独立证据数量。

模型能力及 Agent 创作研究卡片提供可复制研发任务单，含固定输入、现有基线、工具契约、专项测试、质量/效率/成本验收、原始证据及最小可复现交付。仅浏览器本地复制，不创建外部工单；未实测不得声称已实现或效果提升。大语言模型兼顾创作决策、视频理解、剪辑规划、创意编程、网页/游戏及三维脚本，比较相同任务下实际可运行、可渲染和可交付结果；不把编码或推理能力直接视为原生图像/视频/三维生成能力。

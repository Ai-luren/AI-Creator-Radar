# P1 历史证据主动补查

历史待审队列单独消费现有规范库中的候选原文指针，不把已有规范库当独立召回真值。仅允许现有官方文章路径白名单、厂商来源配置与唯一规范型号共同验证的 URL；没有原文、非支持的目录/仓库路径、简称歧义分别记录。最多每次三次 URL 请求；同 URL 多型号只读一次，逐型号核验 H1 和文章日期；尊重原文恢复器退避，同主机失败后不继续请求。历史日期不受近期45天窗口限制。文章日期和明确标题声明仍不自动推断事件日期、首发日或其他型号；候选证据进入历史任务记录并关联对账项，保留首次验证时间。原始待审缺口不因文章存在而自动关闭。首次历史修复只读验证时报告真实网络结果。新增公开文件 `historical-evidence.json`，生产独立事务，不依赖 Mac、搜索付费 API 或代理。

验收范围：有合法既有指针的历史文章主动探测；并非全量历史发布证明。未知指针或不受支持的官方目录、GitHub 仓库及服务变体仍需其他证据通道。原固定样本召回不消费此修复队列。
